# 🚀 Project Overview

Personal Expense Tracker is a Python-based finance management system that records, analyzes, and visualizes personal expenses using CSV files, SQLite, and Streamlit dashboards.

The project helps users:
- Track expenses
- Analyze spending habits
- Monitor monthly budgets
- Generate reports
- Visualize financial trends

This project demonstrates real-world applications of:
- Data Analysis
- Financial Analytics
- Data Visualization
- Dashboard Development
- Database Management

---

# ✨ Features

✅ Expense CSV upload & manual entry  
✅ SQLite database integration  
✅ Automatic expense categorization  
✅ Monthly & category-wise analysis  
✅ Payment method analysis  
✅ Budget tracking & overspending alerts  
✅ Interactive Streamlit dashboard  
✅ Export reports to Excel/CSV
